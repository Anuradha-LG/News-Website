# Dynamic PHP News Website 📰

A dynamic, PHP-based online news website featuring real-time news updates, categorized content, and structured database logic.

⚠️ **IMPORTANT NOTICE:**
Please note that the `main` branch is currently superseded. **The `release-stable-v1.2` branch is the only currently working version.** Please ensure you check out this branch when testing or deploying the project.

## 🚀 Features

* **Real-Time Updates:** Dynamic rendering of the latest news articles (`latest.php`).
* **Categorized Content:** Structured content filtering via the dedicated categories modules (`categories.php`).
* **Admin Dashboard:** Backend management interface (`admin.php`) for content administration.
* **User Interaction:** Contact forms with client-side and server-side validation (`contact.php`, `contact-val.php`, `submit_form.php`).
* **File Management:** Integrated asset and media upload handling (`assets/`, `uploads/`).

## 🛠️ Tech Stack

* **Backend:** PHP (65.2%)
* **Frontend:** CSS (30%), HTML, JavaScript (4.8%)
* **Database:** Structured SQL Logic (Configured via `db.php`)

## 📂 Key Project Structure

* `/assets` - CSS, JavaScript, and static frontend resources.
* `/categories` - Logic and structure for news categorizations.
* `/includes` - Reusable PHP components and structural files.
* `/uploads` - Directory for media and image files.
* `index.php` - Main landing page.
* `db.php` - Database connection configuration.
